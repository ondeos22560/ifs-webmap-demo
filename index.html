DÉMONSTRATEUR

Une proposition de WebMap légère et évolutive

Cette maquette illustre une architecture « carte + filtres + indicateurs + fiches projets » adaptée aux TDR de l’Initiative Fleuve Sénégal. Elle fonctionne directement dans le navigateur et peut être intégrée en iframe.

Front-endLeaflet + JavaScript natif
DonnéesGeoJSON + CSV / API
ÉvolutifPostgreSQL/PostGIS possible
DiffusionPage autonome + iframe

Pour la production : remplacer les géométries de démonstration par les limites administratives officielles validées et connecter l’import à un stockage persistant.
